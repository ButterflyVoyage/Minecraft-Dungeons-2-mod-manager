MCD2 Mod Manager is a Windows application that simplifies every aspect of modding Minecraft Dungeons II. It automatically detects your game, creates the `~mods` folder, installs `.pak` files, and — most importantly — **auto-downloads mods directly from Nexus Mods** using your API key.
